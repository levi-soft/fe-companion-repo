# Fire Emblem Companion for EmuLnk

An EmuLnk repository for Fire Emblem companion themes and game profiles.

## Available

- **Fire Emblem 7 (USA/Australia)** — profile and FE7 Companion theme. Detection uses the original ROM hashes listed in `hashes.json`.

The repository layout follows EmuLnk's v2 repository format. Add other Fire Emblem games as separate profiles and themes when their memory layouts and assets are verified.

## Install

In EmuLnk, set **Repository URL** to the latest release asset (EmuLnk syncs a ZIP archive with repository files at the archive root):

`https://github.com/levi-soft/fe-companion-repo/releases/latest/download/emulnk-repo.zip`

This repository contains FE7-derived portraits, class portraits, item icons, and map tiles for the companion UI. It does not contain a ROM image.
